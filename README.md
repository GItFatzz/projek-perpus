## 📖 Deskripsi
**Aplikasi Perpustakaan** adalah aplikasi desktop VB.NET untuk mengelola data buku dan transaksi peminjaman perpustakaan secara digital dengan **2 Hak Akses** (**Admin** dan **Peminjam**).

---

## ✨ Fitur Utama

### 🔐 Autentikasi
* **Login & Registrasi:** Masuk sesuai hak akses (Admin/Peminjam) atau daftar akun baru.

### 🛠️ Hak Akses: Admin
* **Manajemen Buku:** Tambah dan kelola data buku (ID, judul, penulis, kategori, stok).
* **Data Peminjam:** Lihat daftar dan total anggota yang terdaftar.
* **Laporan Peminjaman:** Pantau riwayat transaksi peminjaman dan status pengembalian buku.

### 👤 Hak Akses: Peminjam
* **Katalog & Pinjam Buku:** Lihat daftar stok buku tersedia dan ajukan peminjaman.
* **Buku Dipinjam:** Pantau ringkasan statistik serta daftar buku yang sedang dipinjam.
* **Riwayat Pinjam:** Cek catatan seluruh buku yang pernah dipinjam.

---

## 🧑‍💻 Platform
* **Bahasa & Framework:** Visual Basic / VB.NET
* **Database:** Sql Server Management Studio (ssms)
* **IDE:** Microsoft Visual Studio
