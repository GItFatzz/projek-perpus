## 📖 Tentang Aplikasi

**Library Management System** adalah aplikasi desktop berbasis C# Windows Forms (.NET) yang dirancang untuk mempermudah pengelolaan koleksi buku dan transaksi peminjaman di perpustakaan secara digital, terstruktur, dan real-time.

Aplikasi ini memisahkan pengalaman pengguna menjadi **2 Hak Akses (Role)** utama, yaitu **Admin** dan **Peminjam**, sehingga keamanan data serta alur kerja perpustakaan dapat berjalan lebih efisien.

---

## ✨ Fitur Utama Berdasarkan Hak Akses

### 🔐 Autentikasi Pengguna
* **Login Multi-Role:** Masuk ke sistem sesuai hak akses masing-masing (Admin atau Peminjam) menggunakan Username dan Password.
* **Registrasi Akun:** Pembuatan akun baru yang praktis untuk pengguna yang belum terdaftar.

---

### 🛠️ Hak Akses: Admin
Dirancang khusus untuk pustakawan atau pengelola dalam mengontrol seluruh data master dan sirkulasi buku:
* **Manajemen Kategori & Data Buku:** Menambahkan koleksi buku baru lengkap dengan ID Buku, Judul Buku, Penulis, Kategori, dan jumlah Stok Buku.
* **Data Peminjam:** Melihat daftar seluruh anggota peminjam yang terdaftar di perpustakaan beserta total jumlah peminjam aktif.
* **Laporan Peminjaman:** Memantau seluruh riwayat transaksi peminjaman, mulai dari username peminjam, judul buku, tanggal pinjam, tanggal kembali, hingga status buku (*Dipinjam* / *Dikembalikan*).

---

### 👤 Hak Akses: Peminjam
Dirancang untuk anggota perpustakaan agar dapat mencari dan meminjam buku dengan mandiri:
* **Katalog Buku:** Melihat daftar buku yang tersedia di perpustakaan beserta informasi penulis, kategori, dan sisa stok secara langsung.
* **Formulir Peminjaman Buku:** Mengajukan peminjaman buku pilihan dengan menentukan jumlah buku, tanggal pinjam, dan tanggal pengembalian.
* **Daftar Buku Dipinjam:** Memantau ringkasan aktivitas pribadi (Total Buku, Buku Dipinjam, dan Buku Dikembalikan) serta daftar buku yang sedang dipinjam.
* **Riwayat Pinjam Buku:** Melihat seluruh catatan buku yang pernah dipinjam sebelumnya secara lengkap.

---

## 💻 Teknologi yang Digunakan
* **Bahasa Pemrograman:** C#
* **Framework:** .NET Windows Forms (WinForms)
* **IDE:** Microsoft Visual Studio

---

## 🚀 Cara Menjalankan Aplikasi
1. Clone atau unduh repositori ini.
2. Buka file solusi (`.sln`) menggunakan **Microsoft Visual Studio**.
3. Pastikan konfigurasi database (jika menggunakan database lokal/SQL Server) sudah terhubung dengan benar.
4. Tekan **F5** atau klik tombol **Start** untuk menjalankan aplikasi.
